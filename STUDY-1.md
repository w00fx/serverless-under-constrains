# Study 1 close-out

**Status: closed.** Study 1 asked whether a refund caller keeps the single-refund invariant when
the provider commits the refund but the caller reaches its deadline before the response arrives
(`COMMIT_THEN_TIMEOUT`). It compares a conventional Lambda and SQS caller with a Lambda Durable
Functions caller. The [specification](study-1/specs/rua/refund-under-ambiguous-outcome.md) is
ratified in `5d16bfe`. No further cloud execution belongs to Study 1. A later billing export can
only add a billing amendment (see [Cost](#cost)).

This note states what ran, what a reader can check, and what is still open. It does not interpret
the results.

## Provenance limit

No third-party timestamp predates the evidence. The repository has no CI. The commits that hold
the oracle code reached GitHub only after all the evidence was frozen.
[`results/study-1/provenance/github-server-timestamps.json`](results/study-1/provenance/github-server-timestamps.json)
records GitHub's own push times. The order "oracle before evidence" therefore rests on three
things that the owner controls:

- **Git commit dates**, which the author sets.
- **The frozen package records.** Each package's admission ran the oracle revision check at the
  package's source commit (`admission/oracle-revision-check.json`). That record is inside the
  package, whose index digest `results.json` cites.
- **Replays.** The first cloud evidence is the rehearsal probe `4f4a29c7`, built from `694d4c9`.
  The owner ran the oracle as it was at `694d4c9` over the canonical run's frozen packages. Every
  committed oracle-result field came out equal, except the evaluation clock `checked_at`. Between
  `694d4c9` and `9ce4ad7`, the trees of the oracle, the evidence-ingestion rules, the
  effect-knowledge model and the golden suite are equal. The files that changed in the oracle's
  import closure parse or collect evidence, and none of them runs during an oracle evaluation.
  The replay records are private (see [Known gaps](#known-gaps)).

`694d4c9` is not an ancestor of the published branch: it was rebased into it as `47042de`.
